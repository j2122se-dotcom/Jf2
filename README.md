# JF2

Base inicial de um hero-shooter para Android.

## Estrutura planejada

- **Modo História:** seleção de personagens, fases e progressão.
- **Regra de morte:** personagem eliminado fica indisponível até o ciclo de personagens reiniciar.
- **Modo Online:** salas, criação de partidas e bots com níveis de dificuldade.
- **Gameplay:** combate em equipes, habilidades e objetivos por fase.

## Estado atual

A primeira versão contém apenas a base Android/Compose e um menu inicial navegável entre História e Online. Sistemas de combate, personagens, mapas, rede e bots serão adicionados em etapas.
