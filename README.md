# Brigada Prisma

Protótipo web de um hero-shooter FPS original, colorido e cartunesco, com campanha, seleção de heróis, salas online simuladas e bots configuráveis.

## Recursos implementados

- Menu principal com História, Online, Personagens/Arsenal, Configurações e Créditos conceituais.
- Cinco heróis originais com função, armas, habilidade, ultimate, personalidade, pontos fortes e fracos.
- Uma missão jogável em mapa original, HUD, tiro simplificado, habilidades e ultimate.
- Sistema de morte na campanha: personagem morto fica indisponível na missão e o jogador escolhe outro.
- Tela visual de disponibilidade dos personagens.
- Codex com capítulos da campanha, inimigos, chefes, recompensas e narrativa.
- Menu online com lista de salas e criação de sala com mapa, modo, bots, dificuldade e senha.
- Persistência em `localStorage` para progresso e estado da campanha.

## Rodar

```bash
npm install
npm run dev
```

## Testar

```bash
npm test
```
